기관 설문 제출 현황

대상 명단과 응답을 비교해, 다음 안내가 필요한 기관을 확인하세요.

교육용 가상 예제 · 실제 현황 아님 브라우저 안에서 비교

01   데이터 연결

필수: 고유한 기관ID, 지역, 기관명. ID가 비거나 중복되면 적용하지 않습니다.

로그인 없이 읽을 수 있는 Sheets CSV만 지원합니다. 설문 작성·결과 요약 링크는 사용할 수 없습니다. 비공개 또는 CORS 오류 시 CSV를 업로드하세요. 개인정보가 있는 전체 응답 시트는 공개하지 마세요.

비교 규칙과 데이터 보호

기관명과 지역은 NFKC 문자 정규화 후 공백만 제거해 정확히 비교합니다. 유사어·포함검색·AI 추측은 사용하지 않습니다. 동명기관은 지역이 일치할 때만 확정하며, 빈 소속과 명단 밖 소속은 확인필요입니다. 지역별 집계는 원본 명단을 기준으로 합니다. 업로드 내용은 서버로 전송하거나 브라우저 저장소에 보관하지 않습니다. Google 연결을 누른 경우에만 입력한 Google 주소에 CSV 읽기를 요청합니다.

자동 갱신 꺼짐

Google 연결 성공 후 자동 갱신을 켤 수 있습니다. 페이지가 열려 있는 동안 작동하며 브라우저 절전·Google 게시 지연으로 즉시 반영을 보장하지 않습니다. CSV는 다시 업로드해야 파일 변경을 읽습니다.

03   기관별 제출 상태

다운로드는 현재 필터와 관계없이 전체 미제출 기관을 포함합니다. CSV는 UTF-8 BOM으로 저장하며 수식으로 해석될 수 있는 값은 보호 처리합니다.
